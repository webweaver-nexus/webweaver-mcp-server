WebWeaver Nexus — MCP Server

A Model Context Protocol server that lets AI assistants reach WebWeaver Nexus directly — read what we do, get in touch, and fill in our contact form without leaving the conversation.

This page is just signposting. The server itself lives at /mcp and speaks JSON-RPC, so opening it in a browser returns 406 Not Acceptable rather than a web page. That is the endpoint working correctly, not an error.

Endpoint

https://webweaver-nexus-mcp.vercel.app/mcp

Streamable HTTP. Public, no authentication required.

Tools

get_contact_form Renders our contact form as an interactive panel inside the assistant.
get_product_overview What WebWeaver Nexus does, and who we build for.
get_contact_info Contact methods and links.

Adding it to a client

In Claude Desktop or claude.ai, add a custom connector pointing at the endpoint above. For clients that only speak stdio, bridge it: 

npx -y mcp-remote https://webweaver-nexus-mcp.vercel.app/mcp
This server is our own Tier 3 deliverable. It is a working example of what we build for clients — securely connecting external AI assistants to a business's own services. Showing it, rather than just describing it.
